# Changelog - Audio Switcher Plus (exe)

What's new in each release of the native exe build, newest first. It isn't on the Marketplace; its package is attached to each GitHub release.

## 1.1.0

- Both for Set Audio Device: one key sets an output and an input together, such as a headset's headphones and mic, and is lit while both are active
- Both for Toggle Audio Device: one key flips between two pairs, each output with its own mic (e.g. headset + headset mic, or speakers + USB mic)
- With Both, an unplugged device is skipped with an alert, and the other one still switches
- New Sound Control Panel key: opens the classic Windows Sound control panel
- New Sound Settings key: opens Sound in Windows Settings
- Both new keys show Windows' own Sound icon
- Set and Toggle keys' settings now have buttons that open both windows
